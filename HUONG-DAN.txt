TUTU Chinese - bộ HTML độc lập

Mở file index.html bằng Chrome hoặc Edge để dùng. Không cần cài đặt hay kết nối mạng.

giao-dien/  : CSS, mã JavaScript giao diện và thư viện nét vẽ.
data/      : Danh sách bài học, ngữ pháp, từ vựng HSK 1-3, dữ liệu nét vẽ và giấy phép.
index.html : Trang web chính.

Bài giảng HSK 1: 15 file HTML trong data/bai-giang/hsk1, gắn đúng số bài.
Bài giảng HSK 2: 15 file HTML trong data/bai-giang/hsk2, gắn đúng số bài.
Bài giảng HSK 3: 18 file HTML trong data/bai-giang/hsk3: Bài 1-18.
Các bài HTML tải về đã chứa sẵn ảnh và âm thanh để mở trực tiếp trên máy.
Bài giảng giữ hình ảnh, âm thanh gốc và các hoạt động tương tác của file bạn cung cấp.
Một số phông chữ của bài giảng tải từ Google Fonts; khi ngoại tuyến, trình duyệt dùng phông chữ trên máy.
Phát âm từng từ dùng chức năng đọc tiếng Trung của trình duyệt và giọng đọc có sẵn trên máy.
Từ đã đánh dấu được lưu trong trình duyệt; việc lưu khi mở file trực tiếp có thể tùy cài đặt trình duyệt.
HSK 1 dùng bộ PDF 512 từ; HSK 2 và HSK 3 dùng dữ liệu ZIP đã bỏ từ trùng.
Bản này chỉ gồm các mục HSK 1-3 có trên giao diện web hiện tại.
